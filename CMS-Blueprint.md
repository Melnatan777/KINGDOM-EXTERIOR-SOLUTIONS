# Kingdom Exterior Solutions CMS Blueprint

## CMS Purpose

Allow the website owner to manage content without editing HTML, CSS, JavaScript, GitHub, or Cloudflare settings.

---

# Dashboard

## Website Overview

Client can view:

* Website status
* Recent updates
* Contact requests
* Published content

---

# Services

Client can:

* Add services
* Edit services
* Delete services
* Change service descriptions
* Change service images

Fields:

* Service Name
* Service Description
* Service Image
* SEO Title
* SEO Description

---

# Gallery

Client can:

* Upload images
* Delete images
* Organize galleries

Fields:

* Image
* Alt Text
* Before/After Category
* Service Category

---

# Reviews

Client can:

* Add testimonials
* Edit testimonials
* Remove testimonials

Fields:

* Customer Name
* Review Text
* Star Rating

---

# Blog Posts

Client can:

* Create blog posts
* Edit blog posts
* Delete blog posts

Fields:

* Title
* Featured Image
* Content
* SEO Title
* SEO Description
